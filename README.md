Overview
---------------------------
This repository reproduces the numerical experiments for the paper

[Interpolating between Optimal Transport and KL regularized Optimal Transport using Rényi Divergences](https://link.springer.com/article/10.1007/s00025-025-02579-z) by [Jonas Bresch](https://jjewbresch.github.io/) and [Viktor Stein](https://viktorajstein.github.io/).
